# Lab 01 - Cisco Packet Tracer Overview

## Overview

Used various cables to connect devices together

**Branches:** New York and Tokyo
**Includes:** Routers, switches, firewalls, PCs, servers, and an external attacker.

## Objectives

* Build the network topology
* Connect network devices
* Identify the roles of routers, switches, and firewalls
* Understand a basic multi-branch network
