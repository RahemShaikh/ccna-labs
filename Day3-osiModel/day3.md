# Lab 03 - The OSI Model

## Overview

Explored simulation mode on Cisco Packet Tracer to simulate traffic and examine OSI Layers on different protocols

**Sites:** Site A (R1): 192.168.1.0/24, Site B (R2): 10.0.0.0/24
**Includes:** 1 server, 1 pc, 2 switches, 2 routers

## Objectives

* Simulate a network to produce traffic
* Examine layer headers on different protocols
* Generate layer 7 traffic via DHCP
* Releasing and renewing Ip configuration
