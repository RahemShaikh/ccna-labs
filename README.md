# CCNA Labs – Networking Fundamentals

A collection of hands-on networking labs completed while studying for the **Cisco Certified Network Associate (CCNA)** certification.

This repository documents my progress in learning networking fundamentals, configuring Cisco devices, and troubleshooting network connectivity using **Cisco Packet Tracer**.

## Technologies & Tools

- **Cisco Packet Tracer** – Network simulation and configuration
- **Cisco IOS CLI** – Router and switch configuration
- **Ethernet & TCP/IP** – Networking fundamentals
- **Git & GitHub** – Lab documentation and version control

## Labs

| Lab | Topics Covered |
|---|---|
| [Day 1 – Packet Tracer Introduction](./Day1-packetTracerIntroduction/) | Packet Tracer interface and network simulation |
| [Day 2 – Connecting Devices](./Day2-connectingDevices/) | Connecting network devices and establishing connectivity |
| [Day 3 – OSI Model](./Day3-osiModel/) | OSI model and network communication |
| [Day 4 – Basic Device Security](./Day4-basicDeviceSecurity/) | Basic Cisco device security and configuration |
| [Day 6 – Analyzing Ethernet Switching](./Day6-AnalyzingEthernetSwitching/) | ARP, MAC address tables, Ethernet frames, and switch learning |
| [Day 8 – Configuring IP Addresses](./Day8-configuringIPAddresses/) | IPv4 addressing, subnet masks, router interfaces, and connectivity testing |

## Skills Developed

- Configuring Cisco routers and switches through the IOS command-line interface.
- Understanding Ethernet switching and MAC address learning.
- Understanding ARP and IP-to-MAC address resolution.
- Configuring IPv4 addresses and subnet masks.
- Establishing and verifying connectivity between different networks.
- Using CLI commands to inspect device configurations and troubleshoot connectivity.

## Repository Structure

Each lab has its own directory containing relevant documentation, network topologies, configuration steps, command references, and key takeaways.

## Progress

Currently working through networking fundamentals and progressively expanding into more advanced CCNA topics, including VLANs, inter-VLAN routing, routing protocols, subnetting, and network troubleshooting.
